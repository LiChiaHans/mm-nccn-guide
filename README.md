# MM 多發性骨髓瘤 — NCCN v2.2027 臨床速查手冊

基於 **NCCN Clinical Practice Guidelines in Oncology: Multiple Myeloma (Version 2.2027, September 24, 2026)** 整理之繁體中文臨床重點與快速查找網站。

## 功能特色
- **章節快速導覽與全文即時搜尋**：支援 `/` 快捷鍵、關鍵字高亮、藥物/基因/分期快速檢索。
- **v2.2027 & v1.2027 重大更新整理**：Ide-cel 分類更正、新增 MRD 原則 (`MYEL-E`)、T 細胞導向治療原則 (`MYEL-G 2/4`)、BCMA 治療後惡化處理 (`MYEL-H 6/6`)、CAR-T/BsAb 無論 IgG 濃度即啟動 IVIG (`MYEL-K`)、MGCS 總表 (`MGCS-1`)。
- **雙互動式臨床計算機**：
  1. **MM 分期與風險綜合計算機**：同步計算 **ISS**、**R-ISS**、**R2-ISS (0–5 分)** 與 **2025 IMS-IMWG 高風險共識**。
  2. **VTE 血栓風險計算機**：即時計算 **IMPEDE** 與 **SAVED** 評分並自動提供對應抗凝／抗血小板預防建議。
- **完整臨床速查表格**：SLiM-CRAB 診斷標準、SMM 20/2/20 風險分層、一線移植/非移植四藥組合、1–3 線依抗藥性分類首選、≥3 線 CAR-T/BsAb、IMWG 療效與 MRD 標準、感染預防與腎功能劑量調整、CNS 骨髓瘤與 MGCS/MGRS/MIDD/MGNS/POEMS。
- **深色 / 淺色模式切換**，支援桌面與行動裝置瀏覽。
